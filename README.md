## ブランチ

- `chap[1-9]*`プレフィクスで始まるブランチには, 該当する章で説明する実装の最終状態が置いてあります.

## TinyDec-HLAの使い方

```
cargo run [デコンパイルしたいELFファイルのパス]
```

## TinyDec-HLAが想定する入力

TinyDec-HLAは教材なので, 他のデコンパイラのように様々なバイナリを扱うことはできません.   
入力として想定されているのは, `gcc -O0`で`x86-64`向けにコンパイルされた`ELF`です. 
この条件を満たさないバイナリは入力されることを想定していません.
